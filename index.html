Side Project

Something I've been building on nights and weekends, outside of the data work above.

Rec'd ItNearly ready for beta

Rec'd It: Recreational Sports League Management

A league and tournament management platform for rec sports. Players get their schedule, one-tap RSVPs, rosters, standings, and team messaging; captains report and confirm scores; league managers get tools for planning seasons, venues, officials, playoff seeding, and sanctions.

I built it database-first on Postgres (through Supabase): one person record for every player, captain, coach, and ref (since the same person can play Tuesday and ref Thursday), one event table for everything from practices to tournament finals, standings computed straight from confirmed scores so they can't drift, and row-level security so people only see what they should. The web app is React and TypeScript, installable on phones as a PWA, and everything in the stack is free and open source.

So far that's 30 database migrations, 19 screens, and a 34-test smoke suite that rebuilds the database from scratch every run. Next up is a beta with a real local league, with dev, UAT, and production environments mapped out on Supabase Cloud and Cloudflare Pages.

Built with Claude Code as my development partner.
