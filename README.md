# narlaq.github.io

The source for my portfolio site, [narlaq.github.io](https://narlaq.github.io). It's plain HTML and CSS with no build step, hosted on GitHub Pages.

The projects it links to each have their own repository:

- [report-ingestion](https://github.com/narlaq/report-ingestion): a Python pipeline that loads PDF and fixed-width reports into SQL Server
- [bikeshare-semantic-model](https://github.com/narlaq/bikeshare-semantic-model): a semantic model in TMDL with calculation groups for time intelligence
